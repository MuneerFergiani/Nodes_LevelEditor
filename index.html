How to use the Level Editor

  • Tap a cell to select it and choose its starting team. Double-click or double-tap to add or remove a building.
  • Drag between two buildings to add or remove their path. Press Escape to cancel a drag.
  • Use +/− on the right for columns and at the bottom for rows. Removing occupied cells needs a second press to confirm.
  • Enable “Create buildings in new cells” to fill added rows or columns; otherwise they start empty.
  • Enable “Connect buildings to neighbours” to add paths between immediate horizontal and vertical neighbours, including newly added buildings. Empty cells are skipped. Turning it off keeps existing paths.
  • Every layout needs four distinct starting buildings, assigned to Players 1–4. Use the layout arrows to switch player-start arrangements. Add creates a layout; Delete removes the current one.
  • Swipe empty space to scroll. Use Undo/Redo to reverse edits.
  • When finished, Export to Clipboard, then paste into Unity’s Level Editor → Import tab. Load JSON resumes an exported level.
